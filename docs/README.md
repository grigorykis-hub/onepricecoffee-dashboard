# OnePriceCoffee Dashboard

Внутренний дашборд для сети кофеен **ONEPRICECOFFEE** (Иваново).  
Показывает ежедневно обновляемые данные по двум точкам, SMM-каналам и рекламным кампаниям.

## ⚙️ Автообновление

Каждый день в **11:00 МСК** GitHub Actions запускает `update_dashboard.py`, который:

1. Забирает новые посты и подписчиков из **VK API**
2. Забирает новые посты из **Telegram** (через scraping)
3. Загружает данные по выручке из **Google Sheets** (текущий месяц ОПВ)
4. Обновляет **VK рейтинг** и отзывы из обсуждений
5. Сохраняет изменения в `index.html` и пушит в репозиторий
6. GitHub Pages автоматически публикует обновление

---

## 🏗️ Технологии

- **Frontend**: чистый HTML/CSS/JS — без фреймворков, без сборки
- **Графики**: Chart.js 4.4.0 (CDN)
- **XLSX-парсинг**: SheetJS (CDN) — только для страницы Таргет VK
- **Автообновление**: Python 3.11 + GitHub Actions
- **Хостинг**: GitHub Pages (бесплатно)
